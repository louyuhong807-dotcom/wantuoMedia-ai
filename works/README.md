# 上传作品

这里存放官网公开展示的作品。请使用有仓库写入权限的 GitHub 账号，在本目录点击 **Add file → Upload files** 上传，并点击 **Commit changes** 确认发布。其他访客只能浏览，不能修改官网作品。

上传后需要等待网站发布完成，再刷新官网查看；本地预览不代表已经公开发布。作品清单由网站自动生成，不需要填写表格或修改代码。

## 文件要求

- 视频：MP4 或 WebM，优先使用 H.264 视频、AAC 音频的 MP4。
- 封面或图片作品：JPG、JPEG、PNG 或 WebP；建议竖版 720 × 1280 像素。
- GitHub 网页上传单文件上限为 25 MiB。建议短视频控制在 20 MB 内、封面控制在 500 KB 内，便于手机浏览。
- 只上传已确定可以公开展示的作品；此目录中的媒体在发布后对所有访客可见。

## 文件命名

同一作品的视频与封面使用相同名称，仅扩展名不同。例如：

```text
01-城市幻想.mp4
01-城市幻想.jpg
02-古风故事.mp4
02-古风故事.webp
03-角色设计.png
```

数字越小，展示越靠前；官网会自动去掉数字前缀，将“城市幻想”“古风故事”等作为标题。数字后用短横线连接作品名。没有数字前缀的作品排在后面。

视频可以单独上传，封面也可以之后补充；只有图片时会作为图片作品展示。同一作品请保留一种视频格式和一张封面，避免重复。名称大小写不同仍可能被识别为同一作品，建议始终保持一致。

请直接把文件上传到本目录，避免名称以点号、下划线或井号开头，不要使用斜杠、反斜杠、问号、井号等特殊字符。

## 修改和删除

- 替换：上传同名文件并提交即可；浏览器缓存可能需要稍后刷新。
- 删除：在 GitHub 删除该作品的视频和封面，提交后等待网站重新发布。
- 修改展示顺序或标题：调整视频与封面的文件名，并保持两者一致。

不要上传 `.nojekyll` 文件，否则会停止生成作品清单。
