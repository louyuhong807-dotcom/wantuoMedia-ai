上传与管理作品

由万拓工作人员上传，发布后在官网公开展示。

上传一组视频与封面，就能更新作品墙。

使用你们现有的 GitHub 管理账号发布。只有拥有网站编辑权限的账号，才能修改公开作品。

  1. 准备视频和封面

    给同一作品的视频和封面取相同名称，例如：

    01-作品名称.mp401-作品名称.jpg

    名称会显示为作品标题，前面的数字决定顺序。也可以只上传图片作品。

  2. 进入上传窗口

    点击下方按钮，用管理账号登录。选择 Choose your files，一起选中视频和封面。

  3. 提交并等待发布

    上传完成后点击 Commit changes。发布完成后刷新作品页，所有访客都能查看。

前往上传作品查看公开作品

上传窗口将在新页面打开；仅选择文件还不会发布，需要在 GitHub 确认提交。

文件要求与后续修改

视频：建议 MP4（H.264），单条不超过 20 MB；GitHub 网页单文件上限为 25 MiB。长片请先导出展示片段。

封面：支持 JPG、PNG、WebP，建议 9:16 竖图、720 × 1280 像素。没有封面时会显示作品标题。

顺序：使用 01、02、03 开头；名称相同的视频与图片会合为一个作品。

替换与下架：同名文件重新上传可替换。下架时在作品目录删除对应视频与封面，提交后重新发布；历史版本仍保留在 GitHub 中。

发布状态：若刚上传还未显示，可先查看发布状态，完成后刷新网页。
